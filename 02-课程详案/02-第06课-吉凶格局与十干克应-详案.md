# 第6课 吉凶格局与十干克应——81种主客关系
> 课次：6/8 · 时长：50min · AI角色：辩论员 · 语料：QM§13, QM§14, QM§21

## 教学目标（objectives）

1. **掌握十干克应的底层逻辑**：理解天地盘天干组合形成81种主客关系的原理，能判断重点组合的吉凶属性与象征含义。
2. **熟记核心吉格与凶格**：能列举九遁、三奇得使、玉女守门等吉格，以及庚格、六仪击刑、三奇入墓、五不遇时等凶格的判定条件。
3. **建立格局判断的系统思维**：学会从"最吉—次吉—中性—次凶—大凶"的梯度评估一局的整体格局质量。
4. **理解主客占验的动静法则**：掌握五阳时利客、五阴时利主的基本规则，能在实际占断中正确区分主客。
5. **AI协作能力**：学会用"辩论员"角色让AI从正反两面论证同一格局的吉凶，培养批判性思维。

## 知识点（knowledge-points）

### KP1：十干克应总述 [来源：QM§13]
十干克应是奇门遁甲判断吉凶的核心技法之一。天盘天干与地盘天干两两组合，十天干共形成10×10=100种组合，扣除重复与特殊情况后归纳为81种主客关系。每一种组合都有固定的吉凶属性和象征含义，是古人长期实践经验的结晶。十干克应的本质是"主客关系"——天盘为客、地盘为主，天盘天干加临地盘天干，反映的是客方对主方的作用关系。判断时需结合用神所落宫位、八门、九星、八神综合分析，不可仅凭干克应一端定吉凶。

### KP2：重点吉组合 [来源：QM§13]
- **戊加戊——伏吟**：天盘戊加地盘戊，凡事闭塞阻滞，求谋不通，凶。但伏吟在特殊格局中可作"守成"之用。
- **戊加丙——青龙返首**：天盘戊加地盘丙，为大吉之格。青龙代表戊土，返首意为回头，象征事情有转机、重新开始、大业可成。谋为大事大吉，但忌墓迫克害。
- **丙加戊——飞鸟跌穴**：天盘丙加地盘戊，大吉之格。飞鸟跌穴比喻鸟归巢穴，象征各得其所、安居乐业。谋为百事吉，尤其利于求财、安葬。
- **丁加乙——玉女守门**：天盘丁加地盘乙，大吉之格。玉女守门比喻丁火玉女把守门户，象征有贵人守护、门户安全。利于婚嫁、求谋、出行。
- **乙加丁——奇仪相佐**：天盘乙加地盘丁，吉格。乙奇得丁仪佐助，谋为可成。

### KP3：重点凶组合 [来源：QM§13]
- **乙加庚——太白入荧**：天盘乙加地盘庚，凶格。太白（庚金）入荧惑（乙木），金克木，象征贼来克我、官灾横祸。主破财、伤灾、官司。
- **庚加乙——白虎猖狂**：天盘庚加地盘乙，凶格。白虎（庚）猖狂克乙，象征强凌弱、横暴之事。主凶伤、争斗、破耗。
- **庚加癸——大格**：天盘庚加地盘癸，凶格。庚为道路，癸为天网，大格主道路坎坷、行人失迷、谋为阻滞。
- **庚加己——刑格**：天盘庚加地盘己，凶格。庚刑己，主刑罚、官司、伤灾。
- **辛加乙——腾蛇夭矫**：天盘辛加地盘乙，凶格。腾蛇夭矫主惊恐、怪异、口舌是非。
- **丁加癸——朱雀投江**：天盘丁加地盘癸，凶格。朱雀投江主文书受阻、音信沉溺。
- **乙加辛——青龙逃走**：天盘乙加地盘辛，凶格。青龙逃走主财帛耗散、奴仆背离。

### KP4：九遁吉格 [来源：QM§14]
九遁是奇门遁甲中最重要的九大吉格，每种遁格都有特定的形成条件和象征意义：
- **天遁**：丙加丁、生门临，主天上遁去，谋为百事吉，尤利出行、升迁。
- **地遁**：乙加己、生门临，主地下遁去，利埋伏、藏匿、求财。
- **人遁**：丁加乙、休门临，主人遁去，利谋事、和合、婚嫁。
- **风遁**：乙加辛、开门临（或生门临），主风遁，利出行、转移。
- **云遁**：辛加乙、生门临，主云遁，利隐避、谋事。
- **龙遁**：乙加癸、休门临（或生门临），主龙遁，利求谋、变化。
- **虎遁**：辛加庚、生门临（或开门临），主虎遁，利威权、争战。
- **神遁**：丙加庚、生门临，主神遁，利求谋、祈福。
- **鬼遁**：丁加癸、生门临（或死门临），主鬼遁，利超度、祭祀。

### KP5：三奇得使与玉女守门 [来源：QM§14]
- **三奇得使**：乙奇得甲午辛、丙奇得甲辰庚、丁奇得甲寅癸，为三奇得使格。三奇得到使唤，主贵人相助、谋为可成。此格需三奇本位不犯墓迫克害方为真得使。
- **玉女守门**：丁奇加临休门，或丁加乙临休门，为玉女守门格。主有玉女把守门户，凡事吉，尤利婚嫁、求谋、守护。
- **三奇贵人升殿**：乙奇临震三宫、丙奇临离九宫、丁奇临兑七宫，各归本位，为三奇贵人升殿格。主贵人到位、谋为大吉。
- **奇游禄位**：乙奇临卯、丙奇临午、丁奇临酉，各得禄位，主财禄丰盈。
- **天显时格**：甲己日的甲子时、甲戌时等六甲时辰，为天显时格。主天显吉象，谋为可成。
- **三诈五假**：三诈（真诈、重诈、休诈）与五假（假令、假义、假和、假仆、假吏），为特殊吉格，主以诈取胜、以假乱真。

### KP6：庚格凶格体系 [来源：QM§14]
庚格是奇门遁甲中最重要的凶格体系，庚金为阻碍、肃杀之神：
- **庚加年干**：主年内有大阻碍、大凶事，如破财、伤灾、官灾。
- **庚加月干**：主月内有大阻碍、大凶事。
- **庚加日干**：主日内有大阻碍、大凶事，克应最速。
- **庚加时干**：主时内有突发凶事。
庚格的凶险程度与所加干的位置有关：加年干最重（影响全年），加时干最轻（仅一时辰）。但庚加日干因克应迅速，实际占断中最为常用。

### KP7：六仪击刑 [来源：QM§14]
六仪击刑是六仪（戊己庚辛壬癸）临于自刑之地的凶格：
- **戊临震三宫**：戊土临震木，木克土，击刑。主官非、伤灾。
- **己临坤二宫**：己土临坤土，同土自刑。主阻滞、耗散。
- **庚临艮八宫**：庚金临艮土，土生金过旺，击刑。主刑伤。
- **辛临离九宫**：辛金临离火，火克金，击刑。主血光、官非。
- **壬临坎一宫**：壬水临坎水，同水自刑。主灾厄、失脱。
- **癸临巽四宫**：癸水临巽木，水临风木，击刑。主口舌、虚惊。
六仪击刑主百事不利，尤忌谋为、出行、求财。

### KP8：三奇入墓与受制 [来源：QM§14]
- **三奇入墓**：乙奇临坤二宫（木墓在未）、丙奇临乾六宫（火墓在戌）、丁奇临艮八宫（火墓在未，一说丁墓在丑），三奇入墓主奇力受困、谋为不通。
- **三奇受制**：乙奇临金宫（乾兑）被克、丙奇临水宫（坎）被克、丁奇临水宫（坎）被克，三奇受制主奇力受损、吉而不吉。
- **时干入墓**：时干所临之宫为时干墓库之地，主谋为不通、百事阻滞。
- **门迫**：八门所临之宫五行克八门本宫五行，如开门临离火被克，主门迫吉门不吉。
- **悖格**：时干加临日干，且时干克日干，主悖逆、不顺。
- **伏吟**：天盘与地盘干支相同，主闭塞、停滞。
- **反吟**：天盘与地盘干支相冲，主反复、变动。
- **五不遇时**：时干克日干（阳克阳、阴克阴），为五不遇时，主百事不宜、大凶。

### KP9：格局判断精要 [来源：QM§21]
格局判断需遵循"先大后小、先吉后凶、综合权衡"的原则：
- **最吉格局**：飞鸟跌穴（丙加戊）、青龙返首（戊加丙）、三奇得使，此三格为奇门最吉之格，遇之谋为百事大吉。
- **大凶格局**：腾蛇夭矫（辛加乙）、朱雀投江（丁加癸）、青龙逃走（乙加辛）、白虎猖狂（庚加丙）、太白入荧（庚加乙），此五格为大凶之格，遇之百事不宜。
- **判断次序**：先看大局（伏吟反吟、空亡），再看格局（吉格凶格），后看用神（所临门星神），最后看主客（动静先后）。
- **吉凶相抵**：一局中吉格凶格并存时，需比较数量与力量。吉多凶少以吉论，凶多吉少以凶论，吉凶相当则以用神旺衰决之。

### KP10：主客占验 [来源：QM§21]
主客占验是奇门遁甲断局的核心法则之一：
- **五阳时利客**：甲乙丙丁戊为五阳时，利客方先动者胜。占断时以天盘为主、客方主动出击。
- **五阴时利主**：己庚辛壬癸为五阴时，利主方后动者胜。占断时以地盘为主、主方静守待变。
- **动静分主客**：动为客、静为主；先动为客、后动为主；天盘为客、地盘为主；进攻为客、防守为主。
- **实际应用**：占战争、竞争、博弈等对抗性事件时，必须先分清主客，再定吉凶。主客不分则吉凶难断。占非对抗性事件（如求财、出行）时，以日干为求测人（主），以所测之事的用神为客。

## 教学步骤（steps）

### 第一步：导入（5min）
从"81种主客关系"切入，提问学员："为什么是81种而不是100种？"引出十干克应的底层逻辑——天盘地盘两两组合扣除特殊情况的归纳结果。展示AI辩论员角色卡。

### 第二步：十干克应精讲（12min）
逐一讲解重点吉组合（戊加丙、丙加戊、丁加乙）和重点凶组合（乙加庚、庚加乙、庚加癸、庚加己），每个组合配象征比喻和实际占断含义。用compare页型对比吉凶组合。

### 第三步：吉格体系（10min）
系统讲解九遁（天遁至鬼遁）、三奇得使、玉女守门、三奇贵人升殿等吉格。强调形成条件和象征意义。用grid卡片展示九遁。

### 第四步：凶格体系（10min）
系统讲解庚格、六仪击刑、三奇入墓、五不遇时等凶格。用表格对比六仪击刑的六种情况。强调凶格的层次——大凶、中凶、小凶。

### 第五步：格局判断与主客占验（8min）
讲解格局判断的次序和主客占验的动静法则。用steps页型展示判断流程。用stats页型展示81种主客关系的统计分布。

### 第六步：AI辩论与课堂测验（5min）
启动AI辩论员角色，让学员用提示词让AI对同一格局从正反两面论证。进行课堂quiz测验。布置课后练习。

## AI融入（prompts）

### Prompt 1：格局辩论员
```
你是奇门遁甲格局辩论员。我将给你一个天盘天干加地盘天干的组合（如"戊加丙"），请从正方（吉）和反方（凶）两个立场分别论证：

【正方论证】
1. 该组合的吉格名称和象征含义
2. 在何种条件下此格应吉
3. 历史占断中的应吉案例

【反方论证】
1. 该组合在何种条件下可能转凶
2. 墓迫克害对该格局的影响
3. 历史占断中的应凶案例

【综合裁定】
给出该格局的总体吉凶评级（大吉/吉/中性/凶/大凶）和适用条件。
```

### Prompt 2：主客分析器
```
你是奇门遁甲主客分析器。我将给你一个时干（如"丙"），请判断：
1. 该时干属五阳时还是五阴时
2. 利客还是利主
3. 客方/主方的行动策略建议
4. 适合的事件类型（对抗性/非对抗性）
```

## 教师侧备注

1. **重点强调**：十干克应是本课核心，81种组合不需要全记，但重点组合（7吉+7凶）必须熟记。
2. **易错点**：学员常混淆"戊加丙"和"丙加戊"——前者是青龙返首（天盘戊加地盘丙），后者是飞鸟跌穴（天盘丙加地盘戊），吉凶虽同为大吉但象征不同。
3. **AI使用建议**：辩论员角色适合让学员理解"格局无绝对吉凶，需结合条件判断"这一核心理念。鼓励学员故意给AI模糊条件，观察AI如何处理不确定性。
4. **衔接下课**：本课产出"格局判断能力"，是第7课"定应期"的格局依据——应期判断需先看格局吉凶，再定应期远近。
5. **时间分配**：十干克应精讲是重点，分配12min；吉格凶格各10min；导入和收尾各5min；AI辩论融入测验环节。
