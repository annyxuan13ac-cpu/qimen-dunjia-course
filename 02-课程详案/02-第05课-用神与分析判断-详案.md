# 第5课 用神与分析判断——竖看横看断吉凶
> 课次：5/8 · 时长：50min · AI角色：侦探 · 语料：QM§10, QM§11

## 教学目标（objectives）
1. 理解奇门64个用神远超六爻6个和大六壬12个的原因，掌握四大特征
2. 掌握竖看法——每个宫位纵向看星干门神四要素及主客关系
3. 掌握横看法——宫与宫生克制化及主客宫生克
4. 理解内外盘主远近快慢的判断依据
5. 掌握月令旺相休囚定用神力量强弱的规则，能用AI侦探角色辅助判断

## 知识点（knowledge-points）

### KP1：64个用神与四大特征 [来源：QM§10]
奇门有64个用神，远超六爻6个和大六壬12个。四大特征：
- 多义性：同一用神在不同事项中含义不同。如开门主事业，但问婚恋时开门可主"开放不专一"
- 多重性：同一事项用多个用神交叉验证。如问财运看生门+日干+时干+月令，多管齐下
- 纲领性：日干=求测人（主），时干=求测之事（客）。日时两干是判断的总纲领
- 系统性：天地人神四盘主客内外盘旺相休囚完整体系，不是单符号判断
- 易错点：多义性最易搞混——开门不总是吉，要看问什么事

### KP2：竖看（纵向分析） [来源：QM§10]
每个宫位竖向看四要素：
- 天盘星：主天时
- 地盘干：主地利
- 八门：主人和
- 八神：主神助
- 主客关系：天盘为客（动方），地盘为主（静方）
- 竖看口诀：一宫之中，星干门神，天客地主
- 示例：坎1宫天蓬星+戊+休门+值符=天时凶地利中人和吉神助吉

### KP3：横看（横向分析） [来源：QM§10]
宫与宫的生克制化：
- 用神宫与日干宫生克：用神宫生日干宫=得力，克日干宫=受阻
- 用神宫与时干宫生克：用神宫生时干宫=事顺，克时干宫=事逆
- 主客宫生克：天盘宫（客）与地盘宫（主）生克
- 同宫天地盘干生克：天盘干克地盘干=客克主，天盘干生地盘干=客生主
- 横看口诀：宫宫生克，主客分明

### KP4：内外盘 [来源：QM§11]
- 内盘：坎震巽离（1/3/4/9四正宫），主近、主快、主内部
- 外盘：乾坤艮兑（6/2/8/7四维宫），主远、主慢、主外部
- 判断：用神落内盘应期近来得快，落外盘应期远来得慢
- 易错点：中5宫属内外盘之间，天禽星寄坤2宫时按外盘论

### KP5：月令旺相休囚 [来源：QM§11]
- 月令决定一切力量强弱
- 用神在月令旺相→有力能成事
- 用神在月令休囚→无力难成事
- 旺相：用神五行与月令同行或月令生用神
- 休囚：月令克用神或用神生月令（泄气）
- 示例：生门属土，春季木旺土囚→生门无力求财难成；秋季金旺土相→生门有力求财可成

## 教学步骤（steps）

### Step 1：开场钩子（5min）
提问："六爻6个用神，大六壬12个，奇门64个——为什么奇门用神这么多？"引出四盘叠合的信息量。AI侦探角色卡：今天AI扮演"判断侦探"，帮你从盘面中找线索断吉凶。

### Step 2：64用神与四大特征（10min）
讲解64用神的来源（四盘叠合），重点讲四大特征。用开门为例演示多义性（问事业吉/问婚恋可能不专一）。强调纲领性：日干主时干客是总纲领。

### Step 3：竖看法（10min）
讲解竖看四要素：星干门神及主客关系。用一个宫位为例完整竖看：坎1宫天蓬+戊+休门+值符，天时凶地利中人和吉神助吉，天盘客地盘主。

### Step 4：横看法（8min）
讲解横看四种生克：用神宫与日干宫、用神宫与时干宫、主客宫、同宫天地盘干。强调横看是宫与宫的关系，竖看是宫内要素的关系。

### Step 5：内外盘与月令（10min）
讲解内外盘主远近快慢，月令定旺相休囚。用生门为例：春季木旺土囚生门无力，秋季金旺土相生门有力。强调月令是力量之源。

### Step 6：找AI的错与总结（7min）
展示AI侦探的判断结果（故意埋3处错：日干为客/外盘主快/月令休囚能成事），让学生找错。总结本课产出"判断方法论"，预告第6课"格局判断的方法论基础"。

## AI融入（prompts）

### 课前预习官
```
你是奇门遁甲判断预习官。请用5句话向学员概括"竖看横看"的判断方法：竖看看什么，横看看什么，内外盘主什么，月令定什么。要求简洁，不超过150字。
```

### 课中角色：侦探
```
你是奇门遁甲判断侦探。用户给你一个已排好的盘面和求测事项，你按以下方法判断：
1.定用神：根据事项选对应用神（问事业看开门/问财运看生门...）
2.竖看：用神所在宫的星干门神四要素+主客
3.横看：用神宫与日干宫/时干宫生克+主客宫生克
4.内外盘：用神落内盘应近快，外盘应远慢
5.月令：用神在月令旺相有力，休囚无力
输出：吉凶判断+依据+应期远近。
不确定时标注"待查"而非编造。
```

### 课后出题官
```
你是奇门遁甲出题官。请围绕"内外盘与月令"出5道单选题，每题4选项附答案解析。第5题为易错题：生门属土落春季木令，旺相休囚？（木克土=囚，求财难成）
```

## 教师侧备注

### 口播锚
- "日干主时干客，竖看星干门神，横看宫宫生克"——判断总纲
- "内盘坎震巽离主近快，外盘乾坤艮兑主远慢"——内外盘口诀
- "月令旺相有力成事，休囚无力难成"——月令口诀

### 易错点
1. 日干是主（求测人），时干是客（求测之事），不要搞反
2. 内盘主近快外盘主远慢，不要搞反
3. 多义性：开门不总是吉，要看问什么事
4. 月令休囚时用神无力，不能断成事
5. 竖看是宫内要素，横看是宫与宫，不要混

### 验收标准
- 学生能口述竖看横看的方法
- 学生能判断用神落内盘外盘
- 学生能根据月令判断用神旺相休囚
- 学生能找出AI判断中的3处错误
